مفاتيح API

المفاتيح تُحفظ في هذا الجهاز فقط ولا تُرسل إلا للخدمة نفسها.

إنشاء جدول المشاريع في Supabase (مرة واحدة)

الصق هذا في SQL Editor ثم شغّله:

create table if not exists projects (
  name text primary key,
  code text not null,
  updated_at timestamptz default now()
);
alter table projects enable row level security;
create policy "open" on projects
  for all using (true) with check (true);

هذه السياسة تفتح الجدول لأي شخص يملك المفتاح. استخدمها للتجربة فقط.

تطبيقاتي

لكل تطبيق خانة اسم وخانة كود، ويُبنى كل واحد كملف APK مستقل.

عند التفعيل يُضاف إلى كل تطبيق المتغيران window.SUPABASE_URL وwindow.SUPABASE_KEY. ضع في المفاتيح مفتاح anon فقط، وليس service_role أبداً.

تعديل بالذكاء الاصطناعي

الكود الحالي يُرسل مع طلبك، والنتيجة تُوضع مباشرة في كود التطبيق داخل تبويب «تطبيقاتي».

بناء APK

كل تطبيق يُبنى كملف APK مستقل ويُثبَّت كتطبيق منفصل على هاتفك. البناء يستغرق نحو 5 دقائق لكل تطبيق، فابقَ في هذه الصفحة.

عند فتح الملف يطلب أندرويد السماح بتثبيت التطبيقات من هذا المصدر. وافق مرة واحدة من شاشة الإعدادات التي تظهر.
